# Windows 資格情報マネージャー（Web 資格情報、リソース名 PADRobot）から読み出す。
# PrimeDrive の値は JavaScript に安全に埋め込めるよう UTF-8 → Base64 にして受け取る。
# ★手で追加 A：PowerShell スクリプトの実行（作成手順.md「3. 手で追加するアクション」）
Text.Trim Text: PsOut TrimOption: Text.TrimOption.Both TrimmedText=> PsOut
Text.SplitText.SplitWithDelimiter Text: PsOut CustomDelimiter: $'''|''' IsRegEx: False Result=> CredParts
SET PdCorpIdB64 TO CredParts[0]
SET PdUserIdB64 TO CredParts[1]
SET PdPasswordB64 TO CredParts[2]
SET RobotToken TO CredParts[3]
SET PsOut TO $''''''
