# PAD フローの作成手順（PrimeDrive 送付キー発行）

`pad/flow.robin.txt` を Power Automate Desktop（PAD、無償版）に貼り付けて、フローを作る手順です。
画面の詳細とセレクターは [画面調査.md](画面調査.md) を参照してください。

> **初回は試運転と微修正が必要です。**
> PrimeDrive 側の JavaScript は、実際の画面で同じコードを動かして確認済みです。
> 一方、PAD のフロー定義（Robin テキスト）は Windows がない環境で書いたため、PAD 上では検証できていません。
> 貼り付けたときにエラーになった行は、下の「貼り付けでエラーになったとき」を見て、同じアクションを画面から追加し直してください。

## 1. 事前準備

| 項目 | 内容 |
|---|---|
| PC | Windows 10/11。ロボット専用の Windows ユーザーを推奨 |
| PAD | Power Automate（Microsoft Store 版または MSI 版）。無償版で動きます |
| ブラウザ | Microsoft Edge（フローは Edge を起動します） |
| Google ドライブ for デスクトップ | ステージングフォルダを同期（例：`G:\共有ドライブ\外部送付ステージング`） |
| PrimeDrive | ロボット用アカウント。アップロード先フォルダ（例：ホーム直下の `外部送付`）を作っておく |
| エラー画像の保存先 | `C:\PAD\PrimeDrive\errors` などのフォルダを作っておく |

### 1-1. ブラウザ拡張の導入

1. PAD を起動し、メニューの **ツール → ブラウザー拡張機能 → Microsoft Edge** を選びます（Edge アドオンストアの「Microsoft Power Automate」が開きます）。
2. 「インストール」を押し、Edge の拡張機能画面で **有効** にします。
3. ほかの拡張機能（広告ブロッカーなど）は、ロボット用プロファイルでは無効にしてください。PAD の JavaScript 実行を妨げることがあります。
4. Edge の設定 → **システムとパフォーマンス → 「スタートアップ ブースト」と「Microsoft Edge が終了してもバックグラウンドの拡張機能およびアプリの実行を続行する」を OFF** にします。ON のままだと、起動したブラウザを PAD が操作できないことがあります。

### 1-2. 資格情報の登録（Windows 資格情報マネージャー）

パスワードとトークンは、フローに直接書かず、ロボット用 Windows ユーザーの資格情報マネージャー（Web 資格情報）に保存します。
ロボット用ユーザーでサインインし、**Windows PowerShell**（5.1）で次を実行してください。値は対話的に入力するので、画面や履歴には残りません。

```powershell
[void][Windows.Security.Credentials.PasswordVault, Windows.Security.Credentials, ContentType = WindowsRuntime]
$vault = New-Object Windows.Security.Credentials.PasswordVault
foreach ($name in 'PrimeDriveCorpId', 'PrimeDriveUserId', 'PrimeDrivePassword', 'RobotToken') {
  $sec = Read-Host -AsSecureString "$name を入力"
  $plain = [Runtime.InteropServices.Marshal]::PtrToStringBSTR([Runtime.InteropServices.Marshal]::SecureStringToBSTR($sec))
  try { $vault.Remove($vault.Retrieve('PADRobot', $name)) } catch {}
  $vault.Add((New-Object Windows.Security.Credentials.PasswordCredential('PADRobot', $name, $plain)))
}
'登録しました'
```

| 名前 | 値 |
|---|---|
| `PrimeDriveCorpId` | PrimeDrive のコーポレートID |
| `PrimeDriveUserId` | ロボット用アカウントのユーザID |
| `PrimeDrivePassword` | ロボット用アカウントのパスワード |
| `RobotToken` | gas/api のスクリプトプロパティ `ROBOT_TOKEN` と同じ値（英数字のみにしてください。`"` `\` `|` は使えません） |

登録した値は「コントロールパネル → 資格情報マネージャー → Web 資格情報」の `PADRobot` で確認・削除できます。
PrimeDrive のパスワードを変えたときは、このスクリプトを再実行してください。

## 2. フローの作成

1. PAD で **新しいフロー** を作成します（名前の例：`PrimeDrive送付キー発行`）。
2. `pad/flow.robin.txt` をテキストエディターで開きます。
3. 先に **サブフロー** を作ります。「サブフロー」タブの **＋** で、次の名前のサブフローを作ります（大文字・小文字も同じにします）。

   `LoadCredentials` / `QueueJob` / `ProcessJob` / `OpenUploadFolder` / `RunJs` / `CloseBrowser` / `CompleteJob` / `FailJob`

4. 各サブフローを開き、`flow.robin.txt` の `FUNCTION <名前> GLOBAL` と `END FUNCTION` の**間の行**をコピーして、デザイナーの作業領域に貼り付けます（Ctrl+V）。
5. 最後に **Main** を開き、`# ---------- Main ----------` から `# ---------- サブフロー ----------` の手前までを貼り付けます。
   貼り付けが終わったら、「3. 手で追加するアクション」に従って `★手で追加` の位置にアクションを追加します。
6. Main 先頭の「設定」を環境に合わせて変更します。

| 変数 | 例 | 説明 |
|---|---|---|
| `ApiUrl` | `https://script.google.com/macros/s/xxxx/exec` | gas/api のデプロイ URL |
| `StagingRoot` | `G:\共有ドライブ\外部送付ステージング` | ステージングフォルダの同期先 |
| `PrimeDriveUrl` | `https://primedrive.jp/v2/browse` | ログイン URL |
| `UploadFolder` | `外部送付` | PrimeDrive のホームからのアップロード先（`/` 区切り。空ならホーム直下）。**事前に作成しておく** |
| `MaxDownloads` | `10` | 送付キーのダウンロード回数の上限 |
| `FileWaitSec` | `600` | ステージングにファイルが届くまで待つ秒数 |
| `MaxJobs` | `50` | 1 回の実行で処理する最大件数（暴走防止） |
| `ErrorShotDir` | `C:\PAD\PrimeDrive\errors` | エラー時のスクリーンショット保存先（事前に作成しておく） |
| `BrowserTitle` | `PrimeDrive*` | Enter キーを送るブラウザのウィンドウタイトル |

7. 変数ペインで次の変数を **機密** にします（右クリック → 「機密としてマーク」）。実行ログや変数ビューに値が表示されなくなります。

   `PdCorpIdB64`, `PdUserIdB64`, `PdPasswordB64`, `RobotToken`, `PsOut`, `CredParts`, `LinkPw`, `Job`, `Res`, `Js`

8. 保存します。

### フローの構成

| サブフロー | 内容 |
|---|---|
| Main | 設定 → 資格情報の読み込み → 承認済みがなくなるまで「取得 → 発行 → 完了／失敗の登録」を繰り返す |
| LoadCredentials | 資格情報マネージャーから PowerShell で読み出す（PrimeDrive の値は Base64 にして JavaScript に渡す） |
| QueueJob | API `queue` で 1 件取り出す（`HasJob`） |
| ProcessJob | ファイル待機 → Edge 起動 → ログイン → 申請 ID のフォルダ作成 → アップロード → 送付キー発行 → URL 取得 → ログアウト。失敗したら `LABEL PdError` に飛び、スクリーンショットを保存してブラウザを閉じる |
| OpenUploadFolder | ホームに戻ってから `UploadFolder` を 1 階層ずつ開く |
| RunJs | 「Web ページで JavaScript 関数を実行」を `OK` / `ERR` が返るまで 1 秒ごとに繰り返す（最大 `JsTimeout` 回） |
| CloseBrowser | ログアウトしてブラウザを閉じる |
| CompleteJob / FailJob | API `complete`（URL と有効期限）/ `fail`（エラー内容） |

PrimeDrive の操作はすべて **「Web ページで JavaScript 関数を実行」** で書いています。UI 要素リポジトリは使いません。
キー操作は、ファイル選択ダイアログを開く `{Enter}` と、「開く」ダイアログへのパスの貼り付け（`{Control}({V}){Enter}`）だけです。

### JavaScript の戻り値

| 戻り値 | 意味 |
|---|---|
| `WAIT` | 画面の準備ができていない。RunJs が 1 秒待って再実行 |
| `OK` / `OK|値|…` | 成功。値は `JsParts[1]` 以降に入る（例：`OK|<URL>|<有効期限>`） |
| `ERR|理由` | 失敗。`ErrMsg` に入り、`fail` で申請に記録される |

同じ名前のフォルダがすでにある場合（再実行時など）は、`<申請ID>_2`, `_3` … の名前でフォルダを作ります。

## 3. 手で追加するアクション

次の 4 種類のアクションは、貼り付けると「不明なアクション」やエラーになることが試運転で分かったため、`flow.robin.txt` には入れていません。
貼り付けたあと、`# ★手で追加 A`〜`D` のコメントの**すぐ下**に、PAD の画面からアクションを追加してください（コメントは残したままでかまいません）。

### A. PowerShell スクリプトの実行（LoadCredentials）

アクション一覧：**スクリプト → PowerShell スクリプトの実行**

| 項目 | 設定 |
|---|---|
| 実行する PowerShell コード | [LoadCredentials.ps1](LoadCredentials.ps1) の中身をそのまま貼り付ける |
| 生成された変数 | 出力を `PsOut`、エラーを `PsErr` に名前変更（名前をクリックして変更） |

確認：その下の「テキストの分割」の後にブレークポイントを置いて実行し、`CredParts` が 4 件になっていれば成功です。
`PsErr` にエラーが出る場合は、1-2 の資格情報の登録を、PAD を実行するのと同じ Windows ユーザーでやり直してください。

### B. Web サービスを呼び出します（QueueJob・CompleteJob・FailJob）

アクション一覧：**HTTP → Web サービスを呼び出します**

| 項目 | 設定 |
|---|---|
| URL | `%ApiUrl%` |
| メソッド | POST |
| 受け入れる | `application/json` |
| コンテンツ タイプ | `application/json` |
| 要求本文 | 下の表 |
| 応答を保存します | テキストを変数に変換します (Web ページ用) |
| 詳細 → リダイレクトに従う | **ON**（Apps Script は 302 を返すため必須） |
| 詳細 → 要求本文をエンコードする | **OFF** |
| 詳細 → エンコード | UTF-8 |
| 詳細 → エラー状態で失敗 | ON |
| 生成された変数 | 応答を `Response` に名前変更 |

| サブフロー | 要求本文 |
|---|---|
| QueueJob | `{"action":"queue","token":"%RobotToken%"}` |
| CompleteJob | `{"action":"complete","token":"%RobotToken%","requestId":"%ReqId%","sendKeyUrl":"%SendKeyUrl%","keyExpiresAt":"%KeyExpiresAt%"}` |
| FailJob | `{"action":"fail","token":"%RobotToken%","requestId":"%ReqId%","message":"%ErrMsg%"}` |

### C. ファイルを待機します（ProcessJob の「1. ステージングにファイルが揃うまで待つ」）

For each の中、`SET ErrMsg …ステージングにファイルが届きません…` の下に追加します。

アクション一覧：**ファイル → ファイルを待機します**

| 項目 | 設定 |
|---|---|
| 次まで待機する | ファイルが作成される |
| ファイル パス | `%JobDir%\%FileName%` |
| タイムアウトで失敗 | ON |
| 期間 | `%FileWaitSec%` |
| エラー発生時 | 「フロー実行を続行する」→ 例外処理モード「**ラベルに移動**」→ `PdError` |

### D. Web ページのスクリーンショットを取得します（ProcessJob の `LABEL PdError` の下）

`If BrowserOpen = True` の中、コメント「ErrorShotDir は事前に作成しておく」の下に追加します。

アクション一覧：**ブラウザー自動化 → Web データ抽出 → Web ページのスクリーンショットを取得します**

| 項目 | 設定 |
|---|---|
| Web ブラウザー インスタンス | `%Browser%` |
| キャプチャ | Web ページ全体 |
| 保存モード | ファイル |
| 画像ファイル | `%ErrorShotDir%\%ReqId%.png` |
| ファイル形式 | PNG |
| エラー発生時 | 「フロー実行を続行する」→ 例外処理モード「**次のアクションに進む**」（スクリーンショットに失敗しても処理を続ける） |

追加が終わったら保存し、サブフローのタブに赤い「!」が残っていないことを確認します。

## 4. 試運転

PAD の **デバッグ（ステップ実行）** で、1 件ずつ確認しながら進めます。

1. **API だけ確認**：申請がない状態で実行し、`QueueJob` の `Res` が `{"ok":true,"job":null}` になり、フローがすぐ終わることを確認します。
2. **テスト申請**：申請アプリで、テスト用の取引先・テストファイル（中身「テスト」の .txt など）で申請し、承認まで進めます。ステージングにファイルが同期されたことを確認します。
3. **ステップ実行**：`ProcessJob` にブレークポイントを置いて実行し、次を順に確認します。
   - Edge が起動してログインできる（`WaitHome` が `OK`）
   - アップロード先に申請 ID のフォルダができ、その中に移動する
   - ファイル選択ダイアログが開き、パスが貼り付けられてアップロードされる
   - ダウンロードリンク発行画面に、有効日数・回数・パスワードが入る
   - `SendKeyUrl` に `https://primedrive.jp/v2/access?key=…` が入る
   - ログアウトしてブラウザが閉じる
4. **申請アプリで確認**：申請が「送付キー発行済み」になり、下書き作成まで進めることを確認します。
5. **受信者側の確認**：URL を別のブラウザ（InPrivate など）で開き、パスワードを入れて「一括ダウンロード」できることを確認します。
6. **エラーの確認**：`UploadFolder` を存在しない名前に変えて実行し、申請が「発行エラー」になり、`ErrorShotDir` に画像が保存されることを確認します。終わったら元に戻します。
7. **後片付け**：PrimeDrive の「ダウンロードリンク一覧」でテストのリンクを無効にし、テストフォルダを削除します。

## 5. 運用

- 無償版の PAD にはスケジュール実行がありません。担当者が PAD を開き、このフローを **手動で実行** します。承認済みの申請がなくなるまで続けて処理し、自動で終わります。
- 実行中は PC を操作しないでください（Enter キーや貼り付けが、別のウィンドウに入ってしまいます）。
- 実行が終わったら、`ErrorShotDir` に新しい画像がないか確認します。発行エラーになった申請は、申請者に通知され、申請画面から再実行できます。
- `PROCESSING_TIMEOUT_MIN`（既定 60 分）以内に `complete`/`fail` が届かない申請は、API 側で自動的に発行エラーに戻ります。PAD を途中で止めた場合も同じです。

## 6. 貼り付けでエラーになったとき

Robin テキストの書式は PAD のバージョンによって少し違うことがあります。「3. 手で追加するアクション」のほかにエラーになった行があれば、同じアクションを画面から追加し、次の値を設定してください。

| アクション（Robin の名前） | 画面での名前 | 設定 |
|---|---|---|
| `WebAutomation.ExecuteJavascript` | ブラウザー自動化 → Web ページで JavaScript 関数を実行 | Web ブラウザー インスタンス：`%Browser%`、JavaScript 関数：`%Js%`、生成された変数：`JsResult` |
| `WebAutomation.LaunchEdge.LaunchEdge` | 新しい Microsoft Edge を起動する | 初期 URL：`%PrimeDriveUrl%`、ウィンドウの状態：最大化、Cookie をクリア：ON |
| `MouseAndKeyboard.SendKeys.FocusAndSendKeysByTitleClass` | マウスとキーボード → キーの送信 | キーの送信先：タイトルやクラスごとのウィンドウ。1 つ目はタイトル `%BrowserTitle%`・クラス `Chrome_WidgetWin_1`・テキスト `{Enter}`。2 つ目はタイトル `開く`・クラス `#32770`・テキスト `{Control}({V}){Enter}` |
| `Clipboard.SetText` / `Clipboard.Clear` | クリップボード → クリップボード テキストを設定 / クリップボードの内容をクリア | |
| `Text.SplitText.SplitWithDelimiter` | テキスト → テキストの分割 | 区切り記号の種類：カスタム、カスタム区切り記号：`|` |
| `ON ERROR … END` | 各アクションの「エラー発生時」 | 「フロー実行を続行する」＋「ラベルに移動」（`PdError`）など、コメントのとおりに設定 |
| `LABEL` / `GOTO` | フロー コントロール → ラベル / 移動先 | |

貼り付けた JavaScript の中にある `\'` は、PAD 上では `'` と表示されます。JavaScript を手で直すときは、ダブルクォート `"`・バックスラッシュ `\`・パーセント記号 `%` を使わないでください（`%` は PAD の変数記号です）。

PrimeDrive の画面が変わって動かなくなったときは、[画面調査.md](画面調査.md) のセレクターを Edge の開発者ツール（F12）で確認し、`flow.robin.txt` の該当する JavaScript を直してください。
